# FDSA_B

A collection of **Fundamentals of Data Structures and Algorithms (FDSA)** practical programs implemented in **C++**.

## 📚 About

This repository contains the practical work completed as part of the FDSA course. It is updated regularly as new practicals and topics are covered throughout the semester.

The repository may include programs related to:

* Data Structures
* Algorithms
* Searching and Sorting
* Linked Lists
* Stacks and Queues
* Trees and Graphs
* Other fundamental DSA concepts

Each practical is organized separately for easy access and reference.

## 🛠️ Language

**C++**

## 🎯 Purpose

The purpose of this repository is to practice implementing data structures and algorithms, improve problem-solving skills, and maintain a record of FDSA practical work throughout the course.
